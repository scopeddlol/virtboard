The first release of Virtboard, a simple soundboard and voice changer for Windows.

![Virtboard](https://raw.githubusercontent.com/scopeddlol/virtboard/v0.1/docs/demo.gif)

### What's included

- Unlimited sounds with global shortcuts that work from the tray
- Pages, each with their own shortcuts
- Voice changer with 13 built-in voices and your own presets
- Trimmer with fades, speed, loop and WAV export
- Volume controls for mic, sounds and headphones
- VB-Audio Virtual Cable detection and one-click install

### Install

1. Download `Virtboard-Setup-0.1.0.exe` below and run it.
2. Let it install VB-Audio Virtual Cable (free), and restart if asked.
3. In Discord, set **Input Device** to **CABLE Output (VB-Audio Virtual Cable)**.

The installer isn't code-signed yet, so Windows SmartScreen may warn you. Choose **More info → Run anyway**.
