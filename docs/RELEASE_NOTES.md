# Virtboard v0.1 🎉

The first release of **Virtboard**, a soundboard and real-time voice changer for Windows that plays into Discord, games and OBS through a virtual microphone.

![Virtboard](https://raw.githubusercontent.com/scopeddlol/virtboard/v0.1/docs/demo.gif)

## Highlights

- 🎛️ **Unlimited sounds**: drag & drop MP3 / WAV / OGG / FLAC / M4A / AAC / WEBM / OPUS
- ⌨️ **Global keybinds** that work from the tray, including numpad & media keys
- 📑 **Pages of sounds**: each page has its own keybind layout, so one key can play different sounds per page
- 🎙️ **Voice changer**: 13 built-in voices plus a full custom preset editor (pitch, robot, bit-crush, distortion, tremolo, filters, EQ, echo, reverb, noise gate)
- ✂️ **Sound trimmer**: waveform trim, fades, speed, loop, play modes, WAV export
- 🎚️ **Mixer**: mic, sounds & monitor volume sliders with live meters
- 🎧 **Optional playback**: hear sounds / your voice on your headphones, globally or per sound
- 🔌 **VB-Audio Virtual Cable** auto-detection and one-click install
- 🪟 Custom title bar, 🧷 tray mode, 🚀 launch on startup, 🎨 six accent themes
- 📦 Custom NSIS installer

## Install

1. Download **`Virtboard-Setup-0.1.0.exe`** below and run it.
2. Accept the offer to install **VB-Audio Virtual Cable** (free), and reboot if its installer asks.
3. In Discord → *Voice & Video*, set **Input Device** to **CABLE Output (VB-Audio Virtual Cable)**.

> The installer is not code-signed yet, so Windows SmartScreen may show *“Windows protected your PC”*. Click **More info → Run anyway**.
